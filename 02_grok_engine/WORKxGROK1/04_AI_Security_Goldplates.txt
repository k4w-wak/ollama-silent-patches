### 2. LiteLLM — The Master Key to Everything
- **CVE-2026-42208** (CVSS 9.3): Pre-auth SQL injection in API key verification path. Exploited within **36 hours** of disclosure. Can extract ALL stored API keys (OpenAI, Anthropic, Google, etc.), create admin keys.
- **TeamPCP Supply Chain**: v1.82.7/1.82.8 backdoored on PyPI — 3-stage credential stealer. 95M monthly downloads affected.
- Default port 4000, often deployed with no auth.

### 3. vLLM Inference Endpoints — GPU Cluster Goldmine
- **CVE-2025-32444**: Pickle deserialization RCE via Mooncake ZeroMQ sockets (v0.6.5–<0.8.5)
- **CVE-2025-48956**: Single large-header GET → memory exhaustion → DoS
- Default unauthenticated API on port 8000. `/v1/models` leaks loaded model names and configs.

### 4. HuggingFace TGI — Model Supply Chain Attacks
- **CVE-2026-0599**: Uncontrolled resource consumption via `fetch_image` → DoS
- **1,500+ exposed API tokens** found on GitHub (Lasso Security)
- Malicious model campaigns: attackers create fake trending models with embedded backdoors
- `torch.load()` pickle deserialization = RCE when loading untrusted models

### 5. Ray Dashboard — The Zombie That Won't Die
- **CVE-2023-6019** (CVSS 10.0): 2+ years old, STILL actively exploited. Command injection via `cpu_profile` param.
- **CVE-2026-27482** (CVSS 6.5): DELETE endpoints unauthenticated → kill Serve deployments, delete jobs
- **ShadowRay 2.0**: Active global campaign — 80,469 attack sessions from 2 IPs over 11 days, self-replicating cryptomining botnet
- **~30,000+** exposed Ray dashboards on the internet
